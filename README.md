What I learned

During this project, I strengthened my understanding of centering layout components using Flexbox and applying semantic markup for better web accessibility.


Here is a snippet of the Flexbox rules used to center the card layout within the viewport:


body {
  display: flex;
  justify-content: center;
  align-items: center;
  background: hsl(212, 45%, 89%);
  width: 100%;
  height: 100vh;
}

I also learned how to write descriptive image alt text to ensure screen readers provide clear context:


<img
  src="./images/image-qr-code.png"
  alt="QR code to visit Frontend Mentor"
